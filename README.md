# Novel Studio

APK বিল্ড: এই ফোল্ডার GitHub repo-তে আপলোড → Actions → "Build APK" → Artifacts থেকে app-debug.apk।

ব্যবহার:
1. ওপরের বারে সার্চ/লিংক দাও (নোভেল সাইট)। নিচে চ্যাটবট (চিপ থেকে বদলাও, ＋ দিয়ে নতুন, লং প্রেসে মোছো)।
2. ● = এই পেজের চ্যাপ্টার কপি। ▶ / ◀ = পরের/আগের চ্যাপ্টারে গিয়ে অটো কপি।
3. চ্যাটবটে পেস্ট করে পাঠাও। উত্তর এলে বটের Copy বাটন চাপো, তারপর 💾 → অনুবাদ সেভ + পরের চ্যাপ্টার কপি।
4. ☰ মেনুতে: নোভেল লিস্ট, সেভ করা অনুবাদ, txt এক্সপোর্ট, প্রম্পট, Ad Block।
