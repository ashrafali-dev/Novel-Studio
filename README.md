# Novel Studio

APK বিল্ড: এই ফোল্ডার GitHub repo-তে আপলোড → Actions → "Build APK" → Artifacts থেকে app-debug.apk।

ব্যবহার:
1. ওপরের বারে সার্চ/লিংক দাও (নোভেল সাইট)। নিচে চ্যাটবট (চিপ থেকে বদলাও, ＋ দিয়ে নতুন, লং প্রেসে মোছো)।
2. ● = এই পেজের চ্যাপ্টার কপি। ▶ / ◀ = পরের/আগের চ্যাপ্টারে গিয়ে অটো কপি (স্ক্রিন মোড বদলায় না)।
3. চ্যাটবটে পেস্ট করে পাঠাও (বা ⚡ অন করলে অটো পেস্ট+সেন্ড)। উত্তর এলে বটের Copy বাটন চাপো, তারপর 💾 → লাইব্রেরিতে সেভ (নোভেলের নাম + চ্যাপ্টার নম্বর সহ) + পরের চ্যাপ্টার কপি।
4. ☰ → লাইব্রেরি: অফলাইনে পড়া, txt এক্সপোর্ট, নাম বদলানো। ডার্ক মোড, Ad Block, প্রম্পট সবই ☰ মেনুতে।
